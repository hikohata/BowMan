# BowMan (弓使いの決闘)

BowManは、角度とパワーを調整して敵を倒すターン制のアーチェリーゲームです。
CPUとの対戦や、同じデバイスでの対人戦（ローカルマルチプレイ）が楽しめます。

## 特徴
- **シンプルで奥深いゲームプレイ**: 角度とパワーを直感的に操作して矢を放ちます。
- **多彩なモード**:
  - **VS CPU**: コンピュータとの対戦モード。ステージが進むごとに敵が強くなります。
  - **VS HUMAN**: 友達と交互に操作して対戦できます。
- **ショップシステム**: 勝利して得たコインで、回復薬や強力な矢（火矢、爆弾矢など）を購入できます。
- **PWA対応**: スマートフォン（Android/iOS）にインストールして、オフラインでもプレイ可能です。

## 遊び方
1. **狙う**: 画面をドラッグして、矢を放つ「角度」と「パワー」を決定します。
2. **撃つ**: 指を離すと矢が発射されます。
3. **風を読む**: 上空の風向きと強さを計算に入れて狙いを定めましょう。
4. **勝利条件**: 敵のHPを0にすれば勝利です。
