# ゲーム開発仕様書：『弓男 - Bow Man -』

## 1. プロジェクト概要

* **タイトル：** 弓男 (Bow Man)
* **ジャンル：** 2Dターン制 砲撃シューティング（Artillery Game）
* **プラットフォーム：** Webブラウザ（PC推奨）
* **コンセプト：** DOS時代の『Tank Wars』の現代的かつシンプルな再現。
* **特徴：** 画面ループ（左右連結）、風の影響、地形破壊、ショップシステム。

## 2. 技術スタック・制約事項

* **言語：** HTML5, CSS3, JavaScript (ES6+)
* **描画：** HTML5 Canvas API (`CanvasRenderingContext2D`)

## 3. ゲームシステム仕様

### 3.1 ゲーム進行フロー

1. **タイトル/設定画面：**
* プレイヤー人数（1～10人）の選択（ローカル対戦/Hotseat方式）。
** CPUプレイヤーを含める場合、CPUの数を設定する。**
* ラウンド数の設定。


2. **戦闘フェーズ（Main Loop）：**
* 地形生成 → プレイヤー配置 → ターン制バトル。
* 最後の一人になるまで継続。


3. **リザルト画面：**
* 順位に応じた賞金の付与。


4. **ショップ画面：**
* 獲得した賞金でアイテム購入・ステータス強化。
* 「次の戦闘へ」ボタンでフェーズ2へ戻る。



### 3.2 物理・環境ルール

* **地形（Terrain）：**
* 画面幅分の1次元配列（ハイトマップ）として管理。
* `terrain[x] = height` の形式。
* **破壊表現：** 爆発が起きた際、その範囲の `y` 値を増加（地面を下げる）させることでクレーターを作る。


* **画面ループ（Screen Wrapping）：**
* 画面の左右は繋がっている。
* 弾（Projectile）が `x > canvas.width` になったら `x = 0` に、`x < 0` になったら `x = canvas.width` に座標変換する。


* **風（Wind）：**
* ターンごとに風向きと強さがランダムに変化。
* 弾のX軸速度に毎フレーム加算される（`vx += wind`）。
* 画面中央上部に矢印または数値で風を表示。


* **重力：**
* 弾のY軸速度に毎フレーム加算される（`vy += gravity`）。



### 3.3 プレイヤー操作・アクション

* **ターン制：** 1人ずつ順番に行動。
* **操作パラメータ：**
* **角度 (Angle)：** 0～180度（または360度）。
* **パワー (Power)：** 0～100の強さ。


* **移動：** 自分のターン中、左右に一定距離だけ移動可能（燃料/スタミナ制）。
* **UI表示：** 現在の角度、パワー、残りHP、風向き、装備中の武器。

### 3.4 武器・アイテム（ショップで購入可能）

* **通常矢 (Normal Arrow)：**
* 弾数無限。標準的なダメージ。小規模な地形破壊。


* **火矢 (Fire Arrow)：**
* 着弾地点の周囲数ピクセルに「炎」オブジェクトを生成。
* 炎に触れると追加ダメージ。


* **爆矢 (Bomb Arrow)：**
* 着弾時に大きな爆発半径を持つ。
* 地形を大きく削り、敵を落下させる用途。


* **回復薬 (Health Pack)：**
* 使用するとHPを即時回復（ターン消費）。



### 3.5 勝敗・ダメージ計算

* **直撃：** 弾の中心とプレイヤーの矩形の衝突判定。
* **爆風ダメージ：** 着弾点からの距離に応じてダメージ減衰。
* **落下ダメージ：** 地形破壊により足場を失い、垂直落下した距離に応じたダメージ。
* **画面外落下：** 画面下部（`height`）を超えて落下した場合は即死。

## 4. UI/UX デザイン（Canvas描画）

* **背景：**
* 単色ではなく、空のグラデーション（夜、夕方、昼などラウンドごとに変化）。
* 背景に簡易的な星や月を描画。


* **プレイヤー：**
* シンプルな矩形または戦車のシルエット。
* プレイヤーごとに色分け（赤、青、緑、黄）。
* 現在の角度を示す「砲身」のラインを描画。


* **エフェクト：**
* 発射時：マズルフラッシュ（円を一瞬描画）。
* 爆発時：オレンジや白の円を拡大・フェードアウトさせるパーティクル演出。

## 6. キーボード操作割り当て

* `←` `→` : 砲身の角度変更
* `↑` `↓` : 発射パワー変更
* `A` `D` : プレイヤーの左右移動
* `W` `S` : 武器切り替え（インベントリ順送り）
* `SPACE` : 発射（長押しではなく、一度押しで決定したパワーで発射）
